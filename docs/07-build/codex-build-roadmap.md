# Codex Build Roadmap

## Phase 0
Repo setup, TypeScript, Next.js, Node.js service structure, Supabase, linting, tests, environment config.

## Phase 1
Brand/design system and responsive primitives.

## Phase 2
Storefront: home, navigation, collections, search, product page, cart.

## Phase 3
Auth, account, addresses, order history.

## Phase 4
Checkout, payment abstraction, test gateway, payment verification and webhooks.

## Phase 5
Admin dashboard, product management, supplier mappings, order management.

## Phase 6
Fulfillment engine, mock supplier, status machine, tracking, retries, idempotency.

## Phase 7
n8n webhook + workflow + logs + notification.

## Phase 8
CJ supplier adapter after API validation.

## Phase 9
AI decision nodes and exception handling.

## Phase 10
Security, accessibility, performance, end-to-end tests.

## Phase 11
Local acceptance.

## Phase 12
Vercel deployment + production integrations.

Rule:
Never ask Codex to build the entire system in one shot. Give it one milestone at a time and require tests after every milestone.
